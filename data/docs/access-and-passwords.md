# Access and Password Standard

Acme Financial (fictional company) - sample document for this demo.

## Passwords

Passwords must be at least 14 characters long. Passwords are not rotated on a schedule, but must be changed immediately if a compromise is suspected. Password managers approved by IT are allowed.

## Multi-factor authentication

MFA is mandatory for remote access, email, and every system that stores Confidential or Restricted data. Hardware security keys are required for administrators.

## Access reviews

Managers review their team's access every quarter. Access for leavers is removed on their last working day. Privileged access is granted just-in-time for a maximum of 8 hours and must be approved by a second person.
